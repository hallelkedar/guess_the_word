# Guess The Word

A terminal-based guess the word game written in Python.

## Requirements

Python 3.x - no external dependencies.

## How to run

```bash
python main.py
```

## Project structure

- `main.py` - entry point
- `game.py` - game logic
- `words.py` - word bank and category management
- `utils/time_utils.py` - day/night utility
